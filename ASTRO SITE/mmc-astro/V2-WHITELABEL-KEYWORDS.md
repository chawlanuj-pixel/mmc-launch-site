# White-label, WordPress and maintenance keyword map

Internal only. Never print volumes on the website.

## Source and how to read the numbers

Source: owner's Google Ads Keyword Planner export, sheet "MMC Keyword Research - Keyword Planner - 2026-10-12" (Google Drive file 1i9YEvxKUBEYrJ2xQyN95-GoPK786GaVBabUxJqCIRIo), read on 2026-10-12. Window Sept 2025 to Aug 2026, Google Search, English, eight locations (India, UAE, Saudi Arabia, UK, Australia, US, Canada, Singapore). Semrush returned `no_api_units`, so there is no SEO keyword difficulty, SERP feature, PAA or competitor data.

Limits that apply to every figure below:
- The ad account has no spend, so volume is a RANGE only (10-100, 100-1k, 1k-10k, 10k-100k). No exact volumes exist.
- "Competition" is paid-search (advertiser) competition: Low/Medium/High. It is NOT SEO keyword difficulty. No KD values are given anywhere.
- Bid is the top-of-page bid high in INR (all markets), a proxy for commercial value, not a traffic number.
- Trend flags (rising/declining, +900%, -90%) are rounding artefacts of range data. Directional only.
- Only the top 100 rows per run were read, so a term missing from the sheet means "no data returned", not "no demand".
